# ネコビタンステージ外部仕様調査

確認日: 2026-10-23（JST）

対象: 日本版にゃんこ大戦争 JP15.7.1 の原本定義と、公開Web情報の照合。原本IDと日本語タイトルの対応は依頼者が提供した原本確認情報を採用しており、Webが内部IDを証明したとは扱わない。

## 要点

- PONOS公式ヘルプで確認できるのは、ネコビタン一般の用途と消費の説明まで。ネコビタンステージ各マップの一覧、開催時間、個別の解放条件、日次上限は公式公開情報から確認できなかった。
- 英語Battle Cats Wikiの現行Catamin Stages記事は47マップを列挙し、挑戦上限とCatamin消費、通常版の一部ステージをプレイするとCatamin版が解放される仕様を説明する。依頼者提示の旧マタタビ5件を除く原本47件と件数が一致し、名称・費用・挑戦回数の照合に使える。ただし日本語版/JP15.7.1の一次証拠ではない。
- 同Wikiは「当初0:00–8:00、2019-06-10以降の月曜終日を経て、後に24/7へ変更」と記す。一方、battlecats-db.comの現行スケジュールは日付によりXP等を「終日」、その他を「00～08時」と分ける実例がある。対象記事・リージョン・版の差を解消する証拠はなく、JP15.7.1の全47マップに単一時間帯を割り当てることはできない。
- Game8の現行狂乱記事は狂乱9種について「一度挑戦すれば、勝敗を問わずネコビタンステージに常設」と明記し、ネコビタンA×2、定期開催も継続とする。Game8の現行イベントスケジュール記事は大狂乱も「一度挑戦すれば追加」と記す。これは狂乱・大狂乱18件の追加条件を支持するが、「常設/いつでも」が24時間入口を意味するかは特定しない。
- 2020年のVer9.8記録は狂乱と「一部のサイクロン、降臨」が追加されたと記すが、対象を網羅せず、対象マップ名も特定しない。英語Wikiは下表の降臨・サイクロン群もCatamin一覧に掲載する。従ってB012–023、B033、B035–039、B049の現行JPでの初回条件・再挑戦表示・開催時間は個別にUNKNOWNとした。
- 現行B050（超極悪ゲリラXP）とB051（悪マタタビ）は英語Wikiの47件にそれぞれXP Bonanza!、Growing Evilとして載る。両者の日本版入口条件と時刻はUNKNOWN。旧マタタビ5件はGame8のVer15.2記事がCataminから削除と説明するため、現行候補から除外する根拠はある。
- 「ネコビタンで強襲の挑戦権回復」は別機能。PONOS公式ヘルプは強襲マップの回復にネコビタンAを使えると説明する。通常の強襲対象一覧とCatamin Stageの47マップ一覧を混同しない。

## 時刻・条件の整理

1. 「Cataminコピーがプロフィール/通常マップの進捗条件で解放される」ことと、「ネコビタンステージ入口がどの時間に見えるか」は別の条件である。原本提示のB012–049は通常版と対応するMapConditionsを持つ同一形式、という依頼者のローカル原本確認はこの切り分けを補強するが、外部時間の証拠ではない。
2. Game8の狂乱「常設」「いつでも」は、通常開催日を待たずネコビタンで挑戦できるという意味までは直接支持する。日次入口が24時間か、00–08の開催中だけかを本文は定義しない。
3. 英語Wikiの「later changed to appear 24/7」は常時表示/開催を示唆するが、JP版15.7.1に適用できる一次資料ではない。battlecats-dbの「他」00–08表示はカテゴリを隠すため、該当するB系マップを特定できない。日次表のXP等終日/他00–08の混在は、全対象へ00–08を一律適用する仮説に反する。
4. GameLinkPlusの2018年0:00–7:59記載は、記事自体がVer7.1導入直後で「情報が少ない」と断っている。2019年以降に追加された狂乱/サイクロン/降臨枠や現在のJP版の時刻を説明する証拠として使えない。
5. 強襲のネコビタンAは挑戦権の回復（待機短縮）用途であり、ネコビタン消費型の再挑戦用Catamin mapとは別。PONOSヘルプは強襲マップの回復まで明記するが、B系でいう再挑戦マップの開催時間根拠にはならない。

## 原作準拠変更の証拠判定

- **変更を外部根拠で支えられる候補**: 旧5マタタビの除外（Ver15.2記事）。旧5件は今回の現行候補47件に含めない。
- **Catamin再挑戦としての分類を支えられる候補**: B024–032狂乱9件とB040–048大狂乱9件。Game8に初回挑戦条件（狂乱は勝敗不問）とA×2費用、定期開催継続の記述がある。日内入口時刻は依然不明。
- **存在・費用の候補資料はあるが、JP現行条件の追加証拠がほしい集合**: B012–023、B033–039、B049の降臨/サイクロン等。英語Wikiは対応Catamin mapと費用を列挙し、Ver9.8の日本語更新記録は一部サイクロン/降臨追加を記すが、JP現行のマップ別条件/スケジュールを網羅しない。
- **資源型としての候補**: B005–011、B050–051。DBの旧定期表/日次表が示す時間分類は一定せず、B050・051は旧定期表の列挙に欠ける。47件全てを共通0–8時ルールにするには追加証拠が必要。
- **UNKNOWNのままにする項目**: JP15.7.1でのB012–051全件の入口時刻（24/7・00–08・特別日終日等）、通常版挑戦の要否が資源型にも適用されるか、Catamin版クリア後の対象表示の継続/削除挙動、日次上限のJP版適用・リセット時刻、全降臨/暴風個別での対象条件。

したがってWeb根拠のみで変更する場合、資源群を00–08とする旧資料を全47件へ拡張せず、狂乱/大狂乱18件も「いつでも」を24時間と読み替えない。B012–023、033–039、049を再挑戦群へ一括変更するには、JP15.7.1実機観測または各MapConditionsを満たしたときの入口/日次表の原本記録を証拠として添える。

### 追加後の判断

- **日本版の全Catamin入口が24/7になった時点は確認できない。** 英語Wikiの変更履歴記述はあるが、現行日本DBの日次表が00–08を示し、2026年の日本語Game8が再挑戦群を「常設/いつでも」と呼ぶだけである。日本語資料で24/7化の告知・変更時期を示すものは見つからなかった。
- **JP15.7.1について最も根拠の強い実装判断は、全47件一律の24時間化をしないこと。** 少なくとも現行DBの定期時刻には00–08枠が残る。資源群は日によって終日となる例外が見える一方、その他群は「他」00–08とされる。したがって、旧資源ステージの時間分類をすべての再挑戦群に移すことも、逆に英語Wikiから全群24/7とすることも根拠不足。
- **『常設/いつでも』の意味は、通常マップの月間開催日に拘束されず、通常版に一度挑戦後はCatamin版として再挑戦できること、と解釈するのが資料間で最も整合する。** 入口ボタンが終日出続けることまでは示さない。Game8の狂乱説明は最新級の日本語根拠だが、DBの時刻区分を覆す特定マップ時刻の記録ではない。
- **日次上限は維持する。** 英語Wikiはマップ別の日次回数上限と、イベントが戻った時に回数がリセットされる旨を記載。日本語2020回答も「次のネコビタンステージの期間」で回数が戻るとする。リセットの厳密な時刻（0:00、8:00、11:00等）は公式/現行の個別ソースで確認できずUNKNOWN。0:00–08枠の各日を別開催として保持する現行構造を一つの連続24h開催へ結合すると、原作側の再出現/回数リセット境界を失う可能性があるため、原本の日別行を結合しない実装が安全。
- **終日例外の扱い:** 日本語Q&Aは旧仕様で月曜などの終日開催があったとする。現行DBの日次表示も資源群の終日例を持つが、「他」群は同じ日に00–08と表示される。期間キャンペーンや曜日ごとの例外を含め、1日単位のschedule dataを尊重し、常時開催へ正規化しない。

この補足により、入口availabilityだけを変える場合の方針は「JP15.7.1の現行時刻ソースが示す日別開催窓を維持し、通常版再挑戦コピーもその窓で表示する」。英語Wikiの24/7記述だけを根拠に1本の常時スケジュールへ変更することは推奨しない。個別BマップがDBの「他」に属する内部ID対応は公表資料から確定できないため、原本行の配置は原本データ/実機観測と照合する。
