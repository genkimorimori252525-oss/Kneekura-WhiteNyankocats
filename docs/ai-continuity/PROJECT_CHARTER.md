# PROJECT CHARTER: kneekura-pc-lab

## Core Mission
にーくらの運営を開始し、既存GitHub計画に沿ってレアガチャスケジュール、ステージスケジュール、イベントスケジュール、ログインボーナスなどをPONOSに代わってローカル運営する。

## Constraints
一括実装・一括検証・一括修正で進める。自作ステージの計画にはまだ進まない。AIはPC内で検証し、スマホ受渡し後のゲーム動作は本人が目視で確認する。現在のスマホの育成・消費済みデータを保持する。原作に近い構造を優先し必要最小限の変更にする。Hooksを有効化しない。

## Completion Criteria
Use only the completion conditions explicitly stated by the user. Do not invent missing requirements.
