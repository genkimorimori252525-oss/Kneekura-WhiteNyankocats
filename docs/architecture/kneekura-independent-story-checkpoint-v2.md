# にーくら大戦争 — 独立版の初期ストーリー状態 v2（2026-10-09）

**承認済み初期状態：日本編1〜3章＋未来編1章クリア、各章すべて最高のお宝。**

オーナーが指定した最新版の独立Androidゲーム初期状態。旧Post-EoC文書にある「未来編は未クリア」という値は**新しい独立版の初期状態としては失効**する。ただし旧日本版`SAVE_DATA`研究ツールそのものの対象値やハッシュを、この変更のために書き換えることはしない。

**他の章は初期クリアしない：** 未来編2・3章、宇宙編1〜3章、レジェンドストーリー（SoL）。ステージが**表示・挑戦可能**であっても、クリア履歴・初回報酬の受取済み・限定キャラの所有状態とは区別する。

## 実装場所

- `app/src/main/assets/kneekura-story-bootstrap-v2.json` — 人間が読める、固定済み初期章と安全条件。4章×48ステージ、最高のお宝ランク3。独立版専用。
- `app/src/main/java/jp/kneekura/whitenyankocats/StoryProgressStore.java` — app-private `kneekura-story-progress-v1.json` とAndroid `AtomicFile` で保存。初回作成、既存独立セーブへの**不足分の一回限りの加算**、二度目以降は変更しない。壊れた既存ファイルを勝手に初期化しない。
- `app/src/main/java/jp/kneekura/whitenyankocats/MainActivity.java` — 初回起動時に上記を初期化し、4章クリア・最高のお宝合計192個を示す検証表示。
- `tools/localcore/story_checkpoint.py` / `tools/localcore/kneekura_save_v1.py` — 独立ローカルセーブのPython側も同じ契約を初期値に使用。
- `tests/test_independent_story_itf1_checkpoint.py` — 安全性、章番号、48×4、お宝ランク3、既存セーブの非破壊、他章・キャラ・アイテム非変更を検証。

## 既存ユーザーの進行は上書きしない

独立版用ストーリー領域がまだなければ新設する。以前の独立アプリで進めたものがある場合、4つの承認済み章だけ**既存のクリア数/お宝ランクを下げず**最低状態まで引き上げる。未来編2・3章、宇宙編、SoL、およびキャラ所持・ネコカン・ログイン報酬など別の進行台帳は変更しない。

`policy_revision=2`を一度保存した後は、アプリを再起動しても同じクリア数・お宝を毎回書き戻さない。ステージリストが全解放済みでも、未クリアのステージのクリア報酬を自動付与してはならない。

**重要な実装境界：** 現在のAndroidはStage Fidelity Alphaで、まだ原作型の日本編/未来編ステージ進行UIや、本番戦闘勝利結果をストーリー台帳へ書き戻す処理は完成していない。この作業は**独立版の初期ストーリー保存データの実装**であり、原作ゲームの`SAVE_DATA`、アカウント、H01や利用停止の解除をするものではない。
