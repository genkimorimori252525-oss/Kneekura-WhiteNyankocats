# にーくら運営室 — 基地右上「i」のお知らせ仕様

## 目的

ユーザーが示した本家の「基地右上の i → 運営からのお知らせ」を、**独立したにーくら大戦争のローカル版**に設ける。掲載内容の企画・執筆・日時設定はジョリーのLiveOps運営室が行う。

ただしこの実装は PONOS のサーバー配信画面を呼ばず、PONOSの実際の開催予定や公式告知だと偽らない。HTML/広告/ブラウザ/ネット通信は使わない。**画像は初期段階では付けず、地の文と見出し・日付・カテゴリを優先する。**

## 実装先

- `app/src/main/java/jp/kneekura/whitenyankocats/MainActivity.java` — 基地相当の現行 Stage Fidelity Alpha 画面、右上丸型「i」入口。
- `NoticeActivity.java` — オフラインお知らせ一覧・詳細、カテゴリ色と掲載日、重要記事を上位表示、戻る動作。
- `LocalNoticeRepository.java` — 署名確認済みの独立LiveOps運営パックからカテゴリ/日時/掲載条件を読み、準備中・期限切れ・未来の告知は隠す。曜日・日替わり・月次・期間開催も処理。
- `LocalOpsStore.java` — SHA・revision・公開鍵照合済みの運営パック読込。
- `app/src/main/assets/kneekura-notices-bootstrap.json` — 初回から読める**APK内蔵の案内3件**。外部運営パックが未導入のときだけ表示する。署名付き運営パックがある場合はそちらを優先。
- `ops/seasons/2026-autumn-prototype.json` — 運営記事の原稿・掲載枠と掲載期間。これは開発用 `draft` のまま。ゲームに配布する運営ZIPへ自動昇格させてはいけない。
- `tools/localcore/notice_feed.py` — 端末に持ち込む前に、同じ記事の公開/下書き・掲載時刻/本文をPCで再現。
- `tools/localcore/opsctl.py notices` — 執筆した記事をコマンドで確認できる。

## 今回作った初回のお知らせ

1. **にーくら運営室、始動！**（運営情報）— 完全ローカル独立運営と今後の開催予定の考え方。
2. **にーくらアップデート1.01 — 開発状況**（更新情報）— まどか・ゴジラの仕様は確定、ゲームへの実装・検証はまだ、という現状。
3. **お知らせ・開催予定はオフラインで更新できるで**（重要）— 1ファイルの署名付き更新方式、外部ネットワークなし、前版復元。

いずれも初期開発の実際の進捗に限って案内し、「未実装のステージやガチャが今日開催されている」などの誤情報は出さない。

## 執筆・掲載ルール

各記事には、後から書き換えない一意のローカルID、カテゴリ、見出し、本文、掲載開始日時（JST）、必要なら重要ピン留めを設定する。掲出期限はLiveOps `schedule` の半開区間 `[start,end)` で管理する。

- **カテゴリ**：重要／運営情報／更新情報／イベント／ガチャ／不具合／お知らせ
- **掲載判定**：まず運営パック自体が `status=published` であること。該当記事は `ready=true`、正しい日時かつ未期限切れであること。
- **開催とお知らせは別**：イベントの告知が掲載されても、ステージがプレイ可能になる/報酬を貰えるわけではない。後続のゲーム側イベント/ガチャ/戦闘エンジンでそれぞれ実装を確認する。
- **文中の外部リンク禁止**：運営記事が勝手にPONOS、広告、その他のWebページを開かない。
- **画像**：現段階ではなし。将来的にオーナーのローカル画像素材を使用するなら、署名されたパックと同じハッシュ・サイズ上限検証、白リスト化されたアセットID、ネット通信不要を満たしたものだけ採用する。
- **履歴保存**：過去の記事は content ID と版番号で記録。掲載終了は「削除」ではなく期限/アーカイブ扱いにする。プレイヤーのSAVEを変更しない。
- **広告・購買連動なし**：お知らせは純粋にゲーム運営の情報提供。課金/広告/アカウント通知は含めない。

## ジョリーが執筆時に実行する検証

GitHubのリポジトリルートから：

```powershell
python -m tools.localcore.opsctl validate --pack ops/seasons/2026-autumn-prototype.json
python -m tools.localcore.opsctl notices --pack ops/seasons/2026-autumn-prototype.json --at 2026-10-09T10:30:00+09:00
python -m unittest discover -s tests -p "test_*notice*.py" -v
```

出力は**下書きプレビュー**であって、署名済み運営パックやリリース完了を意味しない。最終的にAndroidへ更新データを載せるときは、別のP-256署名付きZIP発行・端末側の署名照合/前版チェーン検証を通す。
