# 更新002：原作キャッツアイ育成と素材進化の修復

更新001の本人検証で、ディオラムスLv30停止とまどかの第三進化非表示が判明した。所有者の変更指定に従い、XPだけで上限を貫通する方式を外し、原作のキャッツアイ消費・XP購入・進化素材消費・保存を使う。育成のユーザーランク／ステージ解放条件だけを除き、元データの個別上限60/50/20/1と＋上限、進化のLv・素材条件は維持する。

## 直接原因と修正

- 旧育成adapterはcatseye分岐後の`x20 = unit << 8`をキャラ番号と誤認し、Lv30の拒否を解除しなかった。getter末尾の旧adapterも実UIのinline計算では呼ばれなかった。元XP経路へ復元し、rank1600の可否とrank/stage由来の追加可能数だけを適応する。元catseye使用履歴から必要な実行時上限を計算する。
- まどかの第三形態・Lv30・XP100万・素材条件は手元JP15.7.1に存在する。元SAVEの進化可用フラグが0で、ディオラムスの進化済み2とは状態が異なった。まどかを同じLv30・同じ素材で比較し、フラグ0→1だけで原作進化ボタンが出ることを確認した。比較候補は全意味項目と再生成bytesを照合し、変更はこのフラグだけ。
- 所有対象の素材第三進化266体中、旧スマホでは32体に未解放0が残っていた。新初期プロフィールは元TF ID・必要Lv・XP・素材条件がある所有対象だけ、0→1を設定する。進化済み形態や現在レベルは付与しない。ステージ報酬進化・未実装placeholder・通常Lv/＋進化は対象外。
- XP貫通adapterが進化フラグを破壊した証拠はない。二つの問題を別経路として記録する。公開DBのまどかTF追加履歴はVer14.1.1だが、最新版全データとのbyte一致を証明したものではない。
